Foundations Core ML Theory

Traditional Programming vs Machine Learning

Rule-Based
Traditional Programming
Data + Rules (Code)  ==>  Answers
  • Software engineers craft every condition manually.
  • Brittle when facing complex, high-dimensional patterns.
  • Example: Thousands of hardcoded regex rules to detect spam.
Inductive
Machine Learning
Data + Answers (Labels)  ==>  Rules (Model)
  • Algorithms optimize internal weights (θ) directly from data.
  • Learns underlying patterns and generalizes to unseen inputs.
  • Example: Model automatically learns spam probability features.
Regression Hypothesis Representation

Linear Regression: The Hypothesis Function

Univariate (1 Feature)
Simple Linear Line
h_θ(x) = θ_0 + θ_1 * x_1
  • θ_0: Intercept (bias)
  • θ_1: Slope (feature weight)
  • Input: Single attribute (e.g. House Size)
  • Output: Continuous prediction (e.g. Price)
Multivariate (n Features)
Matrix Vectorization
h_θ(x) = θ_0*x_0 + θ_1*x_1 + ... + θ_n*x_n
y_hat = X · θ
  • Dummy feature x_0 = 1 added as bias column.
  • X: Matrix of shape (m, n+1)
  • θ: Parameter vector of shape (n+1, 1)
  • Vectorized dot product computes all predictions in one operation.
Optimization Loss Formulation

Measuring Error: Mean Squared Error (MSE)

Cost Function
J(θ) Loss Formula
J(θ) = (1 / 2m) * Σ (h_θ(x^(i)) - y^(i))^2
  • Residual: Difference between predicted and true value.
  • Squaring penalizes large mistakes much more than minor ones.
  • Division by 2 cancels out neatly when differentiating.
  • Objective: Find parameters θ that minimize J(θ).
Geometry
Strict Convexity (The Bowl)
  • MSE for linear regression is a strictly convex function.
  • Visual shape: A smooth, 3D bowl with a single bottom point.
  • Zero local minima traps!
  • Any local minimum found is guaranteed to be the global minimum.
"Gradient descent on a convex surface is guaranteed to converge to the optimal solution."
Algorithms Gradient Descent

Optimization: Gradient Descent

Intuition
Stepping Down the Foggy Valley
  • You stand on a hill wrapped in dense fog.
  • Feel the slope beneath your feet (compute partial derivative).
  • Take a step in the direction of steepest descent (-∇J).
  • Repeat until the ground becomes completely flat.
The Update Rule
Simultaneous Parameter Update
θ_j := θ_j - α * (1/m) * Σ (h_θ(x^(i)) - y^(i)) * x_j^(i)
  • α (Alpha): Learning rate / step size.
  • All parameters θ_0, θ_1, ..., θ_n are updated simultaneously.
  • Stop when cost reduction is below tolerance ε.
Hyperparameters Tuning Step Size

The Learning Rate (α): Step Size Matters

α Too Small
e.g. 0.00001
  • Steps are tiny.
  • Takes tens of thousands of epochs to converge.
  • Painfully slow execution.
Optimal α
e.g. 0.01 / 0.1
  • Confident downhill strides.
  • Steps naturally shrink as the gradient flattens near the minimum.
  • Smooth, efficient convergence.
α Too Large
e.g. 2.5
  • Overshoots the valley floor.
  • Bounces higher and higher up opposite walls.
  • Diverges to infinity!

From Scratch to Production

From Scratch (NumPy)
Vectorized Implementation
def gradient_descent(X, y, alpha=0.01, iters=1000):
    m = len(y)
    X_b = np.c_[np.ones((m, 1)), X]
    theta = np.zeros((X_b.shape[1], 1))
    
    for _ in range(iters):
        grads = (1/m) * X_b.T.dot(X_b.dot(theta) - y)
        theta = theta - alpha * grads
        
    return theta
Production (Scikit-Learn)
Production API
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

model = LinearRegression()
model.fit(X_train, y_train)
